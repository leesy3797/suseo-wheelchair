# SUSEO Mobility Digital Twin — 시연 시뮬레이터

수서역을 모델로 한 **가상 역사**에서 자율주행 휠체어 플릿과 보행자 흐름을 돌리는 관제 데모입니다. 실측 BIM, 실로봇, 실센서와는 연결되어 있지 않습니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://localhost:5173/` 를 엽니다.

## 시뮬레이터가 보여주는 것

- 가상 B1 대합실 맵(구역 노드, 기둥, 엘리베이터, 충전존, 계단 금지 구역)
- 보행자 에이전트가 복도를 오가며 서로·휠체어를 피함
- 휠체어 3대: 혼잡 비용 A* 전역 경로 + 로컬 포텐셜 회피
- 목적지 도착, 충전 복귀, 막히면 경로 재계획, 근접 회피 이벤트
- 혼잡·수하물 장애물 시나리오, E-STOP, 배차(현재 위치에서 출발, 순간이동 없음)
- 맵 레이어 ON/OFF(경로, LiDAR, 보행자, 금지 구역)
- 대시보드 KPI·텔레메트리는 **시뮬 상태값** (속도, 최근접 거리, 재계획 횟수 등)

## 구조

```text
src/
  App.jsx                 관제 대시보드
  simulation.js           가상 역사, A*, 보행자/로봇 틱
  components/StationScene.jsx   3D 디지털 트윈 뷰
```
