# SUSEO Mobility Digital Twin — 시연 시뮬레이터

수서역의 1층·지하 1층·지하 2층 모델을 보여주는 **가상 역사**에서 자율주행 휠체어 플릿과 보행자 흐름을 돌리는 관제 데모입니다. 실측 BIM, 실로봇, 실센서와는 연결되어 있지 않습니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저에서 `http://localhost:5173/` 를 엽니다.

역사 모델만 단독으로 확인하려면 개발 서버를 실행한 뒤 `http://localhost:5173/map-test.html` 을 엽니다. 이 검수 화면은 대시보드와 시뮬레이션 UI를 불러오지 않고, 네 영역의 원본 OBJ를 직접 표시합니다. 원본 확인 화면은 `srt_suseo_modeling/3.모델링/` 자료가 로컬에 있어야 합니다.

대시보드에 쓰는 경량 모델은 네 OBJ의 지오메트리를 약 40%로 단순화하고, 텍스처를 1024px 이내의 WebP로 변환해 Meshopt 압축 GLB로 저장합니다. 원본은 그대로 두고 산출물만 `public/models/`에 생성합니다. 원본 모델 폴더와 `MATERIALS/`, `mtl/`가 준비된 상태에서 다시 생성하려면 다음 명령을 실행합니다.

```powershell
npm.cmd run models:optimize
```

## 시뮬레이터가 보여주는 것

- 지상건물·B1 중앙홀·B2 대합실·B2 플랫폼의 경량 GLB와 관제용 1F·B1·B2 맵
- 층별 중앙홀, 개찰구, 승강장, 선로, 엘리베이터, 기둥, 계단 금지 구역을 반영한 경량 3D 표현
- 선로·시설물·기둥·금지 구역을 렌더링과 경로/충돌 계산이 함께 참조
- 보행자 에이전트가 1F·B1·B2 각 층에서 복도를 오가며 서로·휠체어를 피함
- 휠체어 3대: 혼잡 비용 A* 전역 경로 + 로컬 포텐셜 회피
- 1F·B1·B2를 한 화면에 표시하고 엘리베이터로 층간 이동하는 휠체어·승객 시뮬레이션
- 목적지 도착, 충전 복귀, 막히면 경로 재계획, 근접 회피 이벤트
- 혼잡·수하물 장애물 시나리오, E-STOP, 배차(현재 위치에서 출발, 순간이동 없음)
- 맵 레이어 ON/OFF(경로, LiDAR, 보행자, 금지 구역)
- 대시보드 KPI·텔레메트리는 **시뮬 상태값** (속도, 최근접 거리, 재계획 횟수 등)

대시보드는 원본 OBJ 대신 최적화된 네 GLB를 렌더링합니다. 출발·도착 지점은 좌표로 지정하며, 경로 계산은 격자 기반 A*로 경계, 통행 불가 시설물, 기둥, 금지 구역과 임시 장애물을 피합니다. 층을 선택해 지점을 다시 지정할 수 있습니다. 독립 맵 검수 화면은 원본 OBJ를 사용하고 주변 환경 OBJ는 제외합니다. 제공 모델은 실측 좌표와 실제 역사 운영 데이터에 연결된 디지털 트윈이 아닙니다. 원본 모델은 파일 크기 때문에 Git에서 제외되어 있습니다.

## 구조

```text
src/
  App.jsx                 관제 대시보드
  simulation.js           가상 역사, A*, 보행자/로봇 틱
  components/StationScene.jsx   3D 디지털 트윈 뷰
scripts/optimize-station-models.js  원본 OBJ 경량화
public/models/             대시보드용 최적화 GLB
```
